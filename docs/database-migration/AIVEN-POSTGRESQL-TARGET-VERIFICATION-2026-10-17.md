### PostgreSQL 17.6 → 18.6 compatibility
- This is a **major-version cross-version migration**, not a connection-string swap. PostgreSQL documents dump/restore or a supported upgrade path for moving between major versions, and recommends application testing against a concurrent target. PostgreSQL 18 release notes identify behavior changes including time-zone abbreviation handling; generated-column defaults and other semantics also warrant schema-specific review.
- Aiven's full service backup is version-specific; it is not a substitute for a portable logical dump for 17→18. Use PostgreSQL 18 client tools for the logical rehearsal dump/restore, subject to source-version support. Preserve schema, extensions, constraints, triggers, grants, sequences, policies (as migration input), and data validation. A source-specific extension or Supabase-managed object may fail or be meaningless on Aiven.
- Source extensions listed above require per-extension checks. Do not run a production version upgrade or alter either source/target configuration as part of this validation.
